# 도란 개인정보 처리 안내

적용일: 2026년 11월 14일

도란은 차량에서 음성으로 대화하고 모바일에서 개인 기록을 확인하는 공모전 시연용 서비스입니다.

## 처리하는 정보와 목적

- Google 로그인에서 제공되는 계정 식별자와 이메일은 사용자 인증과 본인 기록 구분에 사용합니다. Google의 메일·캘린더·연락처 내용은 요청하지 않습니다.
- 음성 인식으로 얻은 대화 텍스트, 작성·수정한 기록과 일기는 대화와 기록 기능을 위해 저장합니다. 차량 마이크 음성 원본은 도란 서버에 전송하거나 보관하지 않습니다.
- 개인화를 허용한 기록에서 관심사·선호·사건 등의 정보를 추출해 다음 대화에 참고합니다. 기록별 제외, 삭제와 개인화 끄기를 제공합니다.
- 차량 정보는 별도로 허용한 경우에만 사용합니다. 지원되는 목적지 도착 여부, 남은 이동시간, 운행 시간·거리와 동승 여부를 대화의 단서로 사용합니다. 앱이 위치를 사용할 때에도 연속 이동 경로나 원시 좌표를 도란 서버에 전송하지 않습니다.
- 연결된 차량의 임의 식별자, 동의 설정, 요청 시각·오류 코드·처리 시간·AI 사용량은 기기 연결과 안정적 운영, 비용 제한에 사용합니다. 일반 운영 로그에 대화 본문이나 인증 비밀값을 남기지 않습니다.

## 외부 서비스에서의 처리

Supabase는 인증·데이터 저장·서버 실행을 담당합니다. 도란의 데이터베이스는 서울 리전에 구성합니다. OpenAI에는 응답과 기록 생성에 필요한 텍스트 및 허용된 관련 기록을 전송합니다. 외부 AI 처리가 모두 한국 안에서 이루어지는 것은 아닙니다. Responses API에는 `store: false`를 사용하지만, 이것이 공급자의 모든 보안 로그 보관을 없앤다는 의미는 아닙니다. 공급자 정책과 계정 설정에 따른 처리가 적용됩니다.

- Supabase 개인정보 안내: https://supabase.com/privacy
- OpenAI API 데이터 처리 안내: https://developers.openai.com/api/docs/guides/your-data
- Google 개인정보 안내: https://policies.google.com/privacy

## 보관과 삭제

개인 기록은 사용자가 보관하는 동안 서비스 데이터베이스에 저장됩니다. 기록을 삭제하면 연결된 대화 원문과 파생 개인화 정보를 삭제하고 관련 AI 일기를 갱신합니다. 직접 수정한 하루 일기도 함께 삭제할지는 삭제 화면에서 선택합니다. 개인화에서 제외한 기록은 일기로 보관하되 이후 개인화 검색에 사용하지 않습니다.

계정 삭제 시 연결된 차량 접근을 해제하고 서비스의 개인 기록과 계정을 삭제합니다. 기기가 오프라인인 동안 요청한 변경은 서버에 전달된 뒤 적용되며, 처리 상태를 화면에 표시합니다. 공급자 백업·보안 로그는 해당 공급자의 보관 정책을 따릅니다. 이미 외부 처리에 전달된 요청의 과거 처리가 취소되는 것은 아닙니다.

## 사용자의 선택

텍스트의 클라우드·AI 처리를 허용해야 음성 대화 기능을 사용할 수 있습니다. 차량 정보 사용은 선택 사항이며 거부해도 기본 대화와 기록을 사용할 수 있습니다. 설정에서 개인화·차량 정보 이용을 변경하고 연결된 차량을 해제하거나 계정을 삭제할 수 있습니다.

개인 기록은 공개 게시판에 게시하지 않습니다. 공개된 개발 저장소에 문의할 때에도 대화 본문, 계정 비밀값 또는 개인 정보를 첨부하지 마세요. 서비스 문의는 앱의 Google 로그인 화면에 안내된 지원 연락처를 이용할 수 있습니다.
