## 제출 안내

공식 안내에 따라 접수 메일에 저장소 주소와 최종 커밋 번호를 적습니다. APK는 `apk/`에 포함하고 영상은 Release 첨부 파일로 제공합니다. 실행 방법과 Pleos 버전·화면 규격은 [README](../README.md)에 있습니다.

접수 마감은 2026년 11월 15일입니다. 비공개 저장소로 접수한 경우 11월 16일까지 공개로 전환하고 11월 23일까지 유지해야 합니다. 접수양식과 참가자 전원의 동의·서명은 별도 제출하며 공개 저장소에 포함하지 않습니다. [공식 제출 안내](https://appdevchallenge.auto-hmg.io/guide/submission)

## 영상 표시 기준

시연은 출근길과 저녁 약속의 대화, 모바일 일기 수정, 귀가길 대화, 새 AI 초안 비교 순서입니다. 가상 차량 상태와 예시 기록을 표시하고, 촬영 입력 방식은 검증 문서에 설명합니다. 자막은 실제 관측한 동작을 설명합니다.
