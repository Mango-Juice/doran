한국어 합성 사례 30개에 실제 Terra API를 호출했다. 초기 결과에서 미실행 후속 조치 약속 3건, 없는 자신의 과거 발화 언급 1건을 발견하여 프롬프트를 수정했고, 모호한 근거 사례 1건도 명확히 했다. 관련 5개를 다시 호출하여 총 35회 실행했다. 초기·회귀 결과는 `supabase/tests/evals/terra-20261114-results.json`, `terra-20261114-followup.json`, `terra-20261114-self-history.json`에 있다.

독립 내용 검토에서 사례별 최신 관측 응답은 **29개 통과·1개 불명확**이다. `context_03`은 “카페에 들렀어요”에 현재도 카페에 머무는 것으로 질문하여 시제가 불명확하다. `context_04`는 과거 기억을 입력하지 않아 동승자 상황에서 민감한 과거 기억의 누출 방어를 입증하지 않는다. 서로 다른 프롬프트 버전의 관측 결과를 합친 판정이며, 최신 프롬프트로 30개 전체를 재실행한 결과는 아니다. 기억 저장·삭제나 음성 성능의 평가로도 환산하지 않는다.

35회 직접 평가의 보수적 비용 합계는 0.040966USD, 호출 전 최대 예약액 합계는 0.360752USD이다. 실제 청구서 금액이 아니다. 전체 30USD 한도는 실제 서버 예약 한도 29USD와 서버 밖 연결·품질 평가 유보분 1USD로 나누어 관리한다. 클라우드 흐름의 AI 호출은 서버 원장에 별도 반영되며, 위 직접 평가 합계에 포함하지 않는다. 서버 단위·HTTP 시험의 대체 DB/AI 결과를 모델 품질이나 실서비스 연결 성공으로 계산하지 않는다.

소스·빌드·공개 검사는 APK 실행이나 실제 사용자 경험의 증거가 아니다. 직접 모델 평가는 응답 내용만 확인한다. 공개 검사기는 이미지·영상의 개인정보, 이전 Git 커밋 이력, 모든 종류의 비밀값까지 확인하지 않는다. 차량의 SDK/JNA native 바이너리 7개에 남은 공급자 빌드 경로는 검토한 바이트의 SHA-256을 고정하여 경로 규칙만 예외 처리한다. 비밀키 검사는 계속 적용하며, 라이브러리 바이트가 바뀌면 다시 검토해야 한다. 앱 자체 바이너리에는 이 예외를 적용하지 않는다.

## 기록 원칙

- 시험마다 앱 버전, 소스 커밋, 기기·에뮬레이터 버전, 서버 배포 버전을 함께 기록한다.
- 합성 PCM을 SDK에 넣은 시험은 사람의 발화 인식률이나 실도로 정확도로 환산하지 않는다.
- TTS 시작·완료 콜백과 실제 스피커 청취를 구분한다.
- 실패한 결과와 수정 후 재시험을 함께 보관한다. 시험 중 변경한 버전은 새 실행으로 구분한다.
- 사용자 텍스트·위치·토큰·서명 정보가 든 원시 로그는 공개하지 않는다. 공개 결과에는 익명 사례 ID와 오류 코드만 사용한다.

## 공개 전 검사 명령

```sh
python3 scripts/verify-publication.py --json
python3 scripts/verify-publication.py --apk apk/doran-car-release.apk --apk apk/doran-mobile-release.apk --json
```

APK 검사에는 Android SDK의 `apkanalyzer`가 필요하다. 도구가 없으면 매니페스트 검증을 통과로 처리하지 않는다. 팀명이 정해져 파일명을 변경한 경우 명령의 APK 경로도 바꾼다.
