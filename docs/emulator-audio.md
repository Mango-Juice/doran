# Mac 에뮬레이터 오디오

Pleos 에뮬레이터의 Mac 직접 출력에서 잡음이 발생할 때 공식 gRPC로 출력 PCM을 수집할 수 있습니다. 이 도구는 APK의 음성 엔진을 바꾸지 않습니다. 수집한 SDK 원음의 파일 청취와 짧은 실시간 재생은 확인했으며, 장시간 실행의 안정성은 별도 검증 대상입니다.

## 실행 조건

[오디오 도구 안내](../scripts/emulator-audio/README.md)의 의존성과 설치된 Android Emulator의 `emulator_controller.proto`가 필요합니다. `launch.py`는 기존 AVD 데이터와 설정을 유지하고 `QEMU_AUDIO_DRV=none`, 48kHz 출력, localhost 인증 gRPC로 기동합니다. 도구를 실행하기 전에 다른 VM과 무거운 네이티브 빌드를 종료합니다.

`stream_output.py`는 기본적으로 원음을 수집하며 `--play`를 명시해야 호스트에서 재생합니다. 재생용 gain은 보관 PCM에 적용하지 않습니다. `inject_microphone.py`는 `--record-microphone`를 명시한 경우에만 실제 마이크를 수음합니다. 마이크를 사용하지 않는 시연에 이 옵션을 사용해서는 안 됩니다.

접속은 `127.0.0.1`과 비공개 discovery의 인증 토큰을 사용합니다. 토큰 값, 개인 장치명, 녹음과 원시 로그를 공개 저장소에 넣지 않습니다. 출력 폴더는 실행마다 새로 지정합니다.

## 녹화 시 주의할 점

수신 PCM의 패킷 순서와 벽시계 시간은 다릅니다. idle 구간이 압축될 수 있으므로 원본 WAV를 그대로 영상 아래에 붙이지 말고 같은 촬영의 패킷 시각과 공통 음향 구간으로 정렬합니다. 영상과 소리를 임의로 늘이거나 줄이지 않습니다.

도구의 400ms 버퍼 제한은 애플리케이션 내부 범위이며 OS·재생기·스피커까지의 전체 지연 상한이 아닙니다. SDK 콜백과 파일 생성만으로 실제 청취 품질을 통과 처리하지 않습니다. [검증 범위](verification.md)
