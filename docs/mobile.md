# 모바일 앱

## 구조와 화면

`lib/domain`은 기록·하루 일기 모델과 KST 날짜를, `lib/data`는 HTTP 계약·보안 저장소를, `lib/ui`는 화면을 담당합니다. Riverpod은 인증 상태와 저장소 생명주기를 관리합니다. 사용자가 바뀌면 화면을 새로 만들고 진행 중 응답의 소유자를 다시 확인합니다.

오늘 화면은 날짜, 하루 일기, 시간순 개별 대화로 구성합니다. 기록 탭에서 과거 기록을 찾고, 설정에서 개인화·차량 연결·계정을 관리합니다. SUIT 글꼴과 청색 강조색을 차량 앱과 공유합니다. [시각 기준](design-direction.md)

## 로그인과 저장

Google 로그인은 시스템 브라우저와 PKCE를 사용합니다. redirect는 `app.doran.mobile://auth-callback`입니다. 공개 URL과 publishable key만 앱에 포함하고 비밀키는 서버에서 관리합니다. 로그인 세션·PKCE verifier와 계정별 캐시·편집 초안은 Flutter Secure Storage에 보관합니다.

초기화 중에는 준비 화면을 표시하고 10초 이후 재확인을 제공합니다. 진행 중인 초기화는 재사용하며, 실패한 클라이언트가 정리된 뒤에만 새 시도를 시작합니다. 이전 화면이나 계정으로 시작한 응답은 새 화면에 반영하지 않습니다.

접근이 거절된 HTTP 401/403 응답을 오프라인 캐시로 대체하지 않습니다. 네트워크 오류일 때만 해당 계정의 캐시를 읽고 오프라인 상태를 표시합니다. 변경은 서버에서 확인한 뒤 완료로 표시합니다.

## 기록 편집

직접 수정한 하루 일기는 AI 생성본과 분리해 보존합니다. 새 초안이 생기면 비교 후 반영할 수 있습니다. 마지막 개별 기록을 삭제해도 남아 있는 수동 일기를 계속 표시하며, 내용 없는 AI 초안은 비교 대상으로 보여 주지 않습니다.

저장소 쓰기는 순서대로 처리합니다. 버전 충돌 시 최신 서버 본문을 보여주고 작성한 내용을 유지합니다. 덮어쓰기는 명시적으로 선택해야 하며, 날짜·개인화 제외 설정은 실제 변경한 항목만 전송합니다.

삭제 화면은 개별 기록과 원문·파생 기억의 제거 범위를 안내합니다. 직접 쓴 같은 날짜 일기를 함께 지울지는 별도로 선택합니다. 하루 전체 삭제는 해당 날짜의 원문·기록·일기·파생 기억을 제거합니다.

서버 변경 이벤트, 화면 복귀, 당겨서 새로고침으로 기록을 갱신합니다. 전면 화면에서는 30초 간격 조회도 수행합니다. 로그아웃·계정 삭제 시 계정별 로컬 기록과 초안을 지웁니다.
