# 도란 화면 개편

2026-11-14. `frontend-design`을 우선 적용하고 `unslop`은 보조 기준으로 사용한다. 기능·계정·저장·주행 제한을 유지하면서 차량과 모바일의 시각 구조를 바꾼다.

## 기존 화면 진단

- 차량: 상태와 조작이 떨어져 있고 실제 내용이 없는 오른쪽 카드가 화면의 절반을 차지한다. 음성 상태보다 여백과 카드 경계가 먼저 보인다.
- 모바일: 브랜드 제목·페이지 제목·설명·날짜가 중복되어 본문을 밀어낸다. 하루 일기와 개별 대화가 같은 카드 모양이라 관계가 잘 드러나지 않는다.
- 편집: 긴 본문 아래에 저장이 있어 키보드가 열린 상태의 마무리가 어렵다. 내 수정본과 새 AI 초안의 역할을 더 명확히 구분해야 한다.
- 공통: 크림·갈색 조합, 획일적인 둥근 카드, 일반적인 안내 문구가 도란만의 사용 흐름을 설명하지 못한다.

## 방향

- 제품: 차에서 나눈 말을 개인의 하루 기록으로 이어 주는 대화 앱.
- 성격: 차분함, 또렷함, 사적인 기록.
- 배경: 차 안의 짧은 말과 이동을 마친 뒤 읽는 기록.
- 중심 장면: 차량의 현재 대화 상태, 모바일의 실제 하루 일기.
- 공통 표시: 두 개의 말 모양이 기록의 줄로 이어지는 작은 정적 표식. 실제 측정값이 아닌 음성 파형을 만들지 않는다.

색은 안개색 `#F5F7F8`, 흰색 `#FFFFFF`, 먹색 `#20292F`, 회색 `#65737B`, 잉크 청색 `#315C78`, 밝은 청색 `#9CC7DE`를 사용한다. 차량 보조 표면은 `#2B373F`, 보조 글자는 `#B7C3CA`다. 강조색은 조작·선택·상태를 설명할 때 쓴다. 오류·삭제의 의미색은 별도로 유지한다.

한국어 UI와 본문에는 SUIT를 사용한다. 기본 400, 조작과 중간 강조 500, 드문 제목 600으로 구분한다. 모바일 본문은 16–17px와 넉넉한 행간, 차량은 22sp 수준의 본문과 큰 상태 제목을 사용한다. 실제 좁은 화면·큰 글자에서 조정한다. 폰트 출처와 OFL은 자산에 동봉한다.

## 구조 비교와 선택

기존 구조를 색상만 바꾸는 안은 거부했다. 똑같은 카드에 파란색을 입혀도 도란의 대화→기록 흐름이 보이지 않기 때문이다. 차량은 상태·조작을 가까이, 모바일은 날짜·일기·원본 대화의 관계를 중심으로 다시 배치한다. 대형 장식이나 생성 이미지는 추가하지 않는다.

차량: 왼쪽 정렬 상태와 바로 아래 조작을 중심으로, 정차 시에만 실제 대화가 오른쪽에 보인다. 좁은 분할 화면에서는 한 열로 전환한다.

```text
도란                                      휴대폰 연결 상태
현재 대화 상태                     내가 한 말 / 도란의 답변
다음에 할 일                       (실제 내용이 있을 때만)
[시작 또는 일시정지] [종료]
정차 상태에서만: 혼자 대화 확인·권한 안내
```

모바일: 날짜가 문맥을 정하고, 하루 일기는 읽을 수 있는 지면으로, 개별 대화는 시간순 행으로 구분한다. 본문은 왼쪽 정렬하며 긴 줄을 제한한다.

```text
도란                              새로고침
11월 14일 토요일                   날짜 선택
하루 일기                         내 수정본 / AI 초안 상태
오늘을 돌아보는 본문
[다듬기] [새 초안 비교: 있을 때만]
나눈 이야기
12:25   대화 내용 요약
12:18   대화 내용 요약
오늘              기록              설정
```

## 보존과 확인 기준

- 실제 요청·권한·소유권·버전·삭제 범위·수동본 보호를 유지한다.
- 차량의 주행 제한과 개인정보 표시 조건을 유지하며, 조작부는 충분한 터치 크기를 확보한다.
- 대기·듣기·응답 준비·말하기·일시정지·저장·오류를 구별한다. 색만으로 상태를 전달하지 않는다.
- 모바일 빈 상태·오프라인·오류·비교·충돌·키보드 상태를 확인한다.
- 반복 애니메이션·가짜 데이터·통계·마케팅 문구는 추가하지 않는다.
- 실제 스크린샷으로 시각 검토하고 기능 회귀 시험을 수행한다. 새 APK의 청취 품질은 별도 검증이다.
