# 도란 시각 기준

도란의 공통 표식은 말풍선에서 기록의 세 줄로 이어집니다. 차량의 대화 상태와 모바일의 하루 일기가 중심입니다. 영상과 기능 소개 이미지도 실제 앱의 글꼴·색·표식을 사용합니다.

## 색과 글꼴

| 역할 | 색 |
|---|---|
| 모바일 바탕 | 안개색 `#F5F7F8` |
| 본문 지면 | 흰색 `#FFFFFF` |
| 본문·차량 바탕 | 먹색 `#20292F` |
| 보조 글자 | 회색 `#65737B` |
| 모바일 강조 | 잉크 청색 `#315C78` |
| 차량 강조 | 밝은 청색 `#9CC7DE` |

차량 보조 표면은 `#2B373F`, 보조 글자는 `#B7C3CA`입니다. 강조색은 조작·선택·상태에 사용하고 삭제·오류는 별도 의미색으로 구분합니다.

한국어 UI와 영상 자막에는 SUIT를 사용합니다. 본문 400, 조작 500, 제목 600을 기준으로 합니다. 긴 본문은 왼쪽 정렬하고 읽기 편한 줄 길이를 유지합니다. [글꼴 출처와 라이선스](fonts.md)

## 화면 구성

차량은 현재 대화 상태와 바로 아래의 조작을 한 영역에 모읍니다. 정차한 넓은 화면에서만 실제 대화를 별도 영역에 보여 줍니다. 좁은 분할 화면에서도 일시정지와 종료 조작을 유지합니다. 상태는 문장으로 전달하며 가짜 음성 파형이나 반복 장식 애니메이션을 쓰지 않습니다.

모바일은 날짜가 기준입니다. 하루 일기는 읽는 지면으로, 개별 대화는 시간순 목록으로 구분합니다. 편집의 저장 버튼은 키보드 위에 유지하고 직접 쓴 글과 새 AI 초안을 나란히 비교합니다.

실제 시연은 화면 조작과 응답을 보여 주며, 캡처 위 자막이 본문과 조작부를 가리지 않게 배치합니다.

기능 소개 문구는 이동 중 이야기를 나눌 상대, 말로 생각을 정리하는 경험, 따로 글을 쓰는 부담 감소, 일상을 다시 돌아보는 순서로 구성합니다. 배경은 단색에 가깝게 유지하고, 그라데이션은 화면과 글보다 먼저 눈에 띄지 않을 정도로만 사용합니다.

간격·색·타이포그래피 검토에는 Damir Sokolovsky의 [Unslop](https://heydamir.design/unslop), CC BY 4.0 지침을 참고했습니다. UI와 공통 표식은 이 프로젝트에서 작성했습니다.
