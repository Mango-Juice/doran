# 모바일 동작 검증

Flutter의 단위·위젯 시험으로 기록 보호와 계정 경계, 차량 연결 화면의 상태 전환을 확인한다. 네트워크는 테스트 안에서만 대체하며 제품 코드에 샘플 로그인이나 가짜 AI 응답을 넣지 않는다.

## 실행

`apps/mobile`에서 고정된 Flutter SDK로 실행한다.

```sh
flutter test --reporter expanded
flutter analyze
```

## 자동 시험 범위

| 영역 | 확인하는 사용자 동작과 경계 |
| --- | --- |
| 날짜 | KST 자정·연도 전환, 원본 시각의 UTC offset 처리 |
| 하루 일기 | 직접 수정한 글과 의도적으로 비운 글을 새 AI 일기로 덮어쓰지 않음 |
| 기록 | 정리 대기 중에도 원문 대체 내용을 유지, 개인화 제외 상태 보존 |
| 동의 | 설정 항목 누락 시 차량 정보·클라우드 동의를 부여하지 않음 |
| 통신 | Bearer·publishable key 전달, URL의 날짜·cursor 인코딩 |
| 오프라인 | 통신 장애에만 같은 계정의 캐시를 표시, 401·403을 성공으로 숨기지 않음 |
| 계정 경계 | 저장소를 생성한 계정에 고정, 변경 전 저장소의 신규 HTTP·캐시·초안 작업 거부, 계정 변경 중 도착한 조회·수정 응답 폐기 |
| 화면 경계 | 계정 변경·로그아웃 시 Navigator의 이전 편집 화면과 동작 제거, 대기 중 초안 저장이 새 계정의 같은 날짜 일기로 이어지지 않음 |
| 캐시 경계 | 보안 저장소 읽기·쓰기 도중 계정 변경 차단, 다른 계정의 캐시·초안 격리 |
| 보안 저장소 | 이전 저장 작업이 끝난 뒤 로그아웃 캐시 삭제, 저장 실패 후에도 후속 삭제 수행 |
| 초안 복구 | 늦게 도착한 기기 초안이 새로 입력하거나 비운 글을 덮어쓰지 않음 |
| 수정 충돌 | HTTP 409 시 입력한 글·초안을 유지, 서버의 최신 글을 확인한 뒤 덮어쓰기 선택, 건드리지 않은 날짜·개인화 제외 변경을 되돌리지 않음 |
| 삭제 | 원본 삭제와 직접 수정한 하루 일기 삭제 범위를 구분, 선택한 범위를 서버로 전달 |
| AI 일기 비교 | ‘내 글 유지’를 선택하면 AI 초안 채택 요청을 보내지 않음 |
| 로그인 | 중복 실행 방지, 오류 후 재시도, 내부 오류 원문을 사용자에게 노출하지 않음 |
| 접근성 | 로그인 화면의 터치 영역·이름·대비, 폭 320px·글자 200%에서 로그인과 안내 접근 |
| 차량 연결 | 정확히 6자리 입력 후 요청, 차량 승인 전 완료 표시 금지, 만료 후 새 코드 입력 |
| 자동 새로고침 | 달력에서 고른 날짜와 읽던 내용을 유지, 추가로 불러온 기록 페이지를 최신 cursor로 갱신, 인증 실패 시 이전 개인 내용 제거 |

## 별도로 확인해야 하는 실제 환경

자동 시험의 통과가 Google OAuth 승인, 클라우드 데이터 격리, Android KeyStore·iOS Keychain 보안, 기기별 접근성 또는 차량 SDK 실행을 증명하지는 않는다. 출시 APK·iOS 시뮬레이터에서 실제 Google 로그인, 앱으로 복귀, 차량의 양쪽 승인, 기록 수정·삭제·동기화, 로그아웃 후 다른 계정 접속을 확인한다.

위젯 시험의 접근성 검사는 Flutter의 [Accessibility Guideline API](https://docs.flutter.dev/ui/accessibility/accessibility-testing)를 사용한다. 실제 TalkBack·VoiceOver 읽기 순서는 기기 시험에서 별도로 확인한다.
