# 1차 평가와 구현

| 평가항목 | 도란의 제안 | 확인할 구현 |
|---|---|---|
| 차량특화성 | 이동 중 떠오른 이야기를 음성으로 남기고 긴 글은 모바일에서 다듬습니다. | 주행 중 본문 제한, 목적지 남은 시간·도착 맥락, 동승 상태에 따른 개인화 제한 |
| 창의성 | 대화를 개별 기록과 하루 일기로 이어가며 사용자의 정정과 편집을 보존합니다. | 사용자 발화 근거의 기억, 수동 일기 보호, 새 AI 초안 비교 |
| 기술 활용성 | Pleos SDK가 대화의 입출력과 차량 맥락을 담당합니다. | SpeechToText·TextToSpeech, NaviHelper, Vehicle, FusedLocation, CarUxRestrictions |
| 사업성 | 혼자 반복 이동하며 하루를 기록하고 싶은 운전자를 초기 타깃으로 설정합니다. | 첫 대화 저장, 모바일 조회·수정, 이후 대화로 이어지는 반복 사용 흐름 |

차량 기능의 실제 지원 상태는 [SDK 범위](car-sdk.md), 구현과 시험의 구분은 [검증 범위](verification.md)에 있습니다. 자동 좌석 판단은 현재 지원 범위에서 제외합니다. 반복 방문·실차 위치 정확도는 실도로 검증 결과로 제시하지 않습니다.

초기 타깃과 반복 사용 가치는 아직 검증할 가설입니다. 실제 MAU·유지율·매출을 측정한 자료는 없습니다. 이후 사용자 시험에서는 첫 대화 완료율, 7일째 재사용 여부, 기록 조회·수정 이유와 운영 비용을 확인할 계획입니다.

공식 1차 평가항목은 차량특화성·창의성·기술 활용성·사업성입니다. 시연 영상과 소스·APK는 선택 제출 가산점 자료이며, 세부 배점은 공개하지 않습니다. [공식 심사 안내](https://appdevchallenge.auto-hmg.io/guide/judging-awards)
