# 한국어 대화 품질 평가

기본 30개와 시각 회귀 2개 사례는 합성 입력이며 실제 사용자 기록이 아니다. 자동 단위 시험 통과를 대화
품질 통과로 계산하지 않는다. 실패한 응답도 보존하며, 프롬프트를 수정한 뒤의 결과와 합쳐 최신 설정이
전부 통과했다고 계산하지 않는다.

## 실제 모델 텍스트 평가

`provider-run.ts`는 앱과 같은 AI 어댑터를 직접 호출한다. 정정 사례의 앞선 대화와 기억 사례의 합성
맥락을 포함한다. `PRIVATE_DOTENV`는 공개 저장소 밖의 키 파일 경로이며, 비밀값은 출력하지 않는다.

```sh
DORAN_EVAL_PRIOR_RESERVED_USD=0 DORAN_EVAL_LIMIT=30 \
  deno run --allow-env --allow-read --allow-write --allow-net \
  tests/evals/provider-run.ts PRIVATE_DOTENV OUTPUT_JSON
deno fmt OUTPUT_JSON
```

이 직접 호출은 DB 예산 차감을 거치지 않으므로 29USD 운영 한도와 별도로 유보한 1USD 안에서 관리한다.
연결 확인에 0.10USD, 평가에는 최대 0.90USD를 배정한다. 실행 전 이전의 **정산된 비용과 미정산 예약액
합계**를 `DORAN_EVAL_PRIOR_RESERVED_USD`에 넣는다. 처음을 제외하고 0으로 재시작하면 안 된다.
완료되어 usage를 받은 호출은 입력 2USD/백만 토큰·출력 5USD/백만 토큰으로 보수 정산하며, 사용량을 알
수 없는 실패는 예약을 유지한다. 프로그램은 각 호출 전 상한을 확인하고 0.90USD 초과 예상 시 호출하지
않는다. 이 값은 실제 청구서와 구분한다.

결과에는 입력·프롬프트·실행기 해시를 보존하고 비공개 경로에 저장한다. 응답 내용은 사례별 판정
기준으로 검토한다. 정상 HTTP 응답만으로 내용 정확성을 통과 처리하지 않는다.

## 배포된 API와 큐 흐름

실행 전 도란 전용 평가 계정으로 Google 로그인하고 차량 연결 및 데이터 처리 동의를 완료한다.
`DORAN_EVAL_CAR_TOKEN`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`를 비공개 환경 변수로 설정한다.
모든 요청은 실제 API를 사용하므로 29USD 운영 예산 제한에 포함된다. 키가 없는 배포는 503으로 실패하며
대체 응답을 만들지 않는다.

```sh
deno run --allow-env --allow-net tests/evals/run.ts
```

표준 출력에는 각 사례의 실제 답변, 지연, 판정 기준이 출력된다. 검토자는 사실 추가·정정 반영·질문
수·개인정보 선제 언급을 판정한다. 최소 30개 전부 검토하고 실패 사례를 수정한 뒤 관련 사례를
재시험한다. 과거 기억·정정은 동일 세션을 사용하는 별도의 통합 시나리오와 함께 확인해야 한다. API
평가 결과를 실제 마이크 음성 인식 또는 TTS 청취 검증으로 표시하지 않는다.

`cloud-flow.py`와 `cloud-privacy.py`는 폐기 가능한 Auth 시험 사용자와 익명 차량의 토큰을
`DORAN_QA_AUTH_FILE`로 지정한 비공개 JSON에서 읽는다. 별도 시험 프로젝트에서 계정을 준비하고
실행기의 공개 프로젝트 주소를 해당 시험 프로젝트에 맞춰 설정한다. 비밀번호 기반 HTTP 시험은 Google
로그인 화면 검증과 구분한다.
